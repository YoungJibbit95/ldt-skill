LittleDevTeam gives your coding agent a structured path from a request to a verified result. The skill's technical name is **`architect-dev-team`**. Use it for a new project, a substantial feature, or a complex refactor.

## How the skill works

1. **Understand:** inspect the request, project state, and actual capabilities.
2. **Plan:** define requirements and a suitable architecture proposal.
3. **Decide:** present you with a concrete proposal and observable goals.
4. **Build:** implement one approved milestone.
5. **Verify:** run relevant checks and review the result.
6. **Continue:** present the concrete result for your evaluation before the next milestone.

Lean, Balanced, and Rigorous profiles adapt effort to the task. Balanced is the default. Profiles do not change approval rules. When real subagents are useful, permitted, and available, the workflow can involve them. The skill does not create its own agent platform.

## What you need

- A configured, signed-in **Codex environment** that can read local skills.
- **Git** to retrieve the documented source revision.
- **Python 3.10 or later** to use the bundled validation helpers. They require no external Python packages.

The skill is a folder of instructions, references, templates, and Python helpers. It does not install a separate `ldt` application. This native workflow does not require you to put your own API key into the skill; Codex manages its own sign-in.
