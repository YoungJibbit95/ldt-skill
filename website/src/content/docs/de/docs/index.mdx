LittleDevTeam gibt deinem Coding-Agenten einen strukturierten Weg vom Auftrag zum geprüften Ergebnis. Der technische Name des Skills ist **`architect-dev-team`**. Du kannst ihn für ein neues Projekt, eine größere Funktion oder eine anspruchsvolle Überarbeitung verwenden.

## So arbeitet der Skill

1. **Verstehen:** Auftrag, Projektstand und tatsächliche Möglichkeiten untersuchen.
2. **Planen:** Anforderungen und einen passenden Architekturvorschlag formulieren.
3. **Entscheiden:** Dir einen konkreten Vorschlag mit überprüfbaren Zielen vorlegen.
4. **Entwickeln:** Einen freigegebenen Meilenstein umsetzen.
5. **Prüfen:** Relevante Checks durchführen und das Ergebnis reviewen.
6. **Fortsetzen:** Dir das konkrete Ergebnis zur Bewertung vorlegen, bevor der nächste Meilenstein beginnt.

Die Profile Lean, Balanced und Rigorous passen den Aufwand an die Aufgabe an. Balanced ist der Ausgangspunkt. Sie ändern die Freigaberegeln nicht. Wenn echte Subagenten sinnvoll, erlaubt und verfügbar sind, kann der Workflow sie einbeziehen. Der Skill erzeugt keine eigene Agentenplattform.

## Was du brauchst

- Eine eingerichtete und angemeldete **Codex-Umgebung**, die lokale Skills lesen kann.
- **Git**, um den dokumentierten Quellstand zu beziehen.
- **Python ab 3.10**, wenn du die mitgelieferten Prüfhilfen verwendest. Sie benötigen keine externen Python-Pakete.

Der Skill ist ein Ordner mit Anweisungen, Referenzen, Vorlagen und Python-Helfern. Ein separates `ldt`-Programm wird nicht installiert. Für diesen nativen Workflow musst du keinen eigenen API-Schlüssel in den Skill eintragen; Codex verwaltet seine eigene Anmeldung.

## Diese Website ist die Demonstration

Wir entwickeln diese Website mit LittleDevTeam: mit einem freigegebenen Plan, getrenntem Arbeitsbereich und kleinen Meilensteinen. Die hier sichtbare erste Website-Etappe umfasst den Einstieg, die Installation und den Guide.

Die interaktive Simulation, die vertiefte technische Referenz und die ausführliche Fallstudie gehören zum anschließenden Meilenstein. Den [freigegebenen Website-Plan](https://github.com/YoungJibbit95/ltd-skill/blob/website/w1-nebula/docs/website-plan.md) kannst du im Repository lesen.
