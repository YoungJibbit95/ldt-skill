## Evidence method and limits

Primary GitHub repository metadata, default-branch commits and full immutable archives were fetched using Python 3.12 standard-library urllib.request/json/zipfile/io/pathlib/concurrent.futures/re. SKILL frontmatter, README, license/NOTICE, plugin manifests and selected helpers were inspected as text. No downloaded script or project code was executed. API quota ran out; NEON, CLICK, MINI and MATT pins were instead extracted from GitHub HTML currentOid and checked against pinned archives and immutable commit .patch headers. Their dates below are author dates; other commit dates are API committer dates. Neither is a skill-specific last-maintained date. Stars and download counts were not used as trust signals.

The exact repo-relative SKILL.md path and actual manifest name are recorded per candidate below. Source IDs resolve to the full immutable commit in this ledger. A directory can be independently addressed without being self-contained: sibling skills, scripts/data, plugin agents/workflows and MCP tools may still be required. No standalone-copy or Codex runtime test was performed.

Classification: **V** = verified-upstream-but-untested; **A** = alias; **F** = fork; **U** = unverified; **X** = deprecated-or-unavailable (absence at current pin, not proof of reason). Runtime declarations are upstream claims. No use of V implies that an entire dependency closure or security audit was completed.

## V2 implications, unresolved facts and future pilots

- Resolve identifiers using owner/repository/full commit/path/**manifest name**. Marketing names, aliases and folder names are not interchangeable. ANTH/VIP frontend-design and OA/VC vercel-deploy collide; LEON/KOM taste names differ. Do not install both an alias and canonical row.
- Preserve distribution closure. Figma connector capability cannot be supplied by SKILL.md; TOB Workflow/agents cannot be assumed from bare directories. Installed Figma 16.0.0 is a separate distribution from OA curated files; exact immutable mapping remains unknown. Specialized installed names are not fabricated GitHub entries.
- Preserve source/license distinctions. AER is an explicit MATT fork, but its accessibility addition is absent from parent. DOTNET and MINI match the same commit; use canonical parent instead of treating a fork as another independent capability. IMP acknowledges ANTH derivation. VIP/KOM conceptual similarity is insufficient to establish lineage. KOM lacks reuse terms; Figma terms are contractual Beta terms; TOB ShareAlike and CLICK NOTICE must not be dropped.
- A single source pin does not freeze effective instructions. VC guidelines, SUPA changelog/docs, NEON parent/live docs and TOB rule documentation pull mutable secondary content. Package managers, React Bits refresh and IMP engine downloads add further independently versioned sources.
